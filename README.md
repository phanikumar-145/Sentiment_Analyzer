# AI Product Review Sentiment Analyzer

An AI-powered application that analyzes product reviews and identifies whether customer feedback is **Positive, Negative, or Neutral**. It uses a Large Language Model (LLM) through the Groq API to generate sentiment analysis, summaries, and key insights from natural-language reviews.

## Overview

The AI Product Review Sentiment Analyzer helps users understand customer opinions without manually reading every review.

Users can enter a product review through a Streamlit interface. The frontend sends the review to a FastAPI backend, which processes it using the Groq API and a Llama 3.1 model.

The application returns:
- **Sentiment:** Positive, Negative, or Neutral.
- **Short Summary:** A brief explanation of the review.
- **Key Insights:** Important points identified from the customer's feedback.

## Features

- Analyze product reviews using AI.
- Classify customer sentiment as positive, negative, or neutral.
- Generate short summaries of customer feedback.
- Extract important insights from reviews.
- Streamlit-based user interface.
- FastAPI backend for handling analysis requests.
- Groq API integration with Llama 3.1.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/phanikumar-145/Sentiment_Analyzer.git
cd Sentiment_Analyzer
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file in the project root directory:

```env
GROQ_API_KEY=your_groq_api_key
```

Replace the placeholder with your own Groq API key.

**Important:** Never upload your API key or other credentials to GitHub.

### 5. Start the FastAPI backend

Open a terminal in the project directory:

```bash
uvicorn main:app --reload
```

The backend will run at:

```text
http://127.0.0.1:8000
```

FastAPI documentation:

```text
http://127.0.0.1:8000/docs
```

### 6. Start the Streamlit frontend

Open a second terminal, activate the same virtual environment, and run:

```bash
streamlit run app.py
```

The Streamlit application will open in your browser.

**Note:** Start the FastAPI backend before using the Streamlit interface because the frontend sends requests to the backend.

## API Endpoint

### Analyze Product Review

**Endpoint:**

```http
POST /analyze-review
```

**Request body:**

```json
{
  "review": "The product quality is excellent and delivery was very fast."
}
```

**Response structure:**

```json
{
  "analysis": "Sentiment: Positive\nShort Summary: The customer is satisfied with the product quality and delivery.\nKey Insights: Excellent product quality and fast delivery."
}
```

The response text is generated by the LLM, so its exact wording may vary.

### Health Check

```http
GET /
```

Returns a message indicating that the sentiment analyzer backend is running.

## How It Works

1. The user enters a product review in the Streamlit interface.
2. The frontend sends the review to the FastAPI `/analyze-review` endpoint.
3. FastAPI validates the incoming request using the review schema.
4. The LLM service sends the review to the Groq API.
5. The Llama 3.1 model analyzes the review and generates sentiment, summary, and insights.
6. The backend returns the generated analysis.
7. The Streamlit interface displays the result.
